# 用 React + Tailwind + shadcn/ui + HeroUI 重写帮助页面

## 调研结论

- kkk 参考项目（`karin-plugin-kkk`）的帮助图前端正是用官方工具链 **`@karinjs/template-react`（ktr）** 实现的：React TSX 模板 → SSR 静态 HTML → karin puppeteer 截图。模板自带 **Tailwind v4 + HeroUI v3 主题**（`@karinjs/template-react/styles` 内置 `@heroui/styles`），与要求的栈完全吻合。
- 本项目条件已具备：node-karin 1.17.0 有 `karinPathHtml` 导出；tsdown 会把 devDependencies 打包进 dist（仅 `deps.neverBundle` 的 node-karin 保持外部），符合 ktr「生产零安装」模式；`@karinjs/plugin-puppeteer` 渲染器已安装。
- kkk 帮助页布局要素：弥散光背景层、噪点纹理、大字背景装饰（GUIDE）、角落点阵/线条/条纹装饰、头部标题区、分组轮换主题色（蓝/紫/青）、指令行 = 图标 + 标题 + 描述、支持子分组。
- 用户已确认：**深色弥散光** 单主题。

## 实施步骤

### 1. 依赖与脚本（package.json）
- devDependencies 新增：`@karinjs/template-react@^0.1.1`、`react`/`react-dom@^19`、`@types/react(-dom)`、`@heroui/react@3.2.4`（Chip/Card 等）、`lucide-react`（shadcn 默认图标）、`clsx` + `tailwind-merge`（shadcn `cn()`）。
- scripts：`template: ktr sync && ktr dev`（本地预览面板 localhost:5180，含一键截图）；`dev` 改为 `ktr sync && cross-env ...`（kkk 同款）；`build` 保持 `tsdown`（ktrBuildPlugin 钩子自动完成注册表同步 + CSS 编译）。

### 2. 构建接入
- `tsdown.config.ts`：引入 `ktrBuildPlugin()`（from `@karinjs/template-react/plugin`），产物 `dist/style.css` + 模板注册表随 outDir 输出；开启 `treeshake` 防止 heroui barrel 全量打包。
- 新增 `karin.template.ts`：ktr `defineConfig`（开发面板端口/主机，对齐 kkk 写法）。
- `tsconfig.json`：加 `"jsx": "react-jsx"`，include 增加 `ktr/**/*`（rootDir 放宽）。
- `.gitignore`：追加 `.ktr/`（ktr sync 产物）；修正裸 `public` 规则（补 `!ktr/` 放行，模板源码需入库）。
- 删除 `resources/template/help.html`（旧 art-template 菜单模板，git 保留历史）。

### 3. React 模板（ktr/ 目录）
```
ktr/
├─ template/
│  ├─ style.css                 # tailwindcss + template-react/styles + @source，深色基调与字体栈
│  ├─ lib/utils.ts              # cn()（clsx + tailwind-merge）
│  ├─ components/ui/            # shadcn 风格 vendored 组件（无 Radix，SSR 安全）
│  │  ├─ card.tsx  badge.tsx  separator.tsx
│  └─ qbot/help/
│     ├─ index.tsx              # defineTemplate({ name: '帮助页面', component: Help })
│     ├─ types.ts               # HelpData 类型
│     ├─ data/default.json      # 开发面板 mock 数据
│     └─ components/
│        ├─ Help.tsx            # 整页：弥散光 + 噪点 + HELP 大字 + 角落装饰
│        └─ HelpGroup.tsx       # 分组卡片（蓝/紫/青 accent 轮换，HeroUI Chip 标签）
```
- 数据结构：`HelpData { pluginName, version, groups: [{ title, tag?, icon?, items: [{ cmd, desc, icon }] }], total }`；icon 用 lucide-react 组件映射。
- 版式（760px 宽，rounded-3xl，`overflow-hidden`，不加 `id="container"`）：头部 = 图标徽章 + 插件名 + HeroUI Chip（版本）+ 副标题；分组卡片 = shadcn Card + 彩色 accent 头部 + 指令行（图标方块 + cmd 等宽字重 + desc 弱化色）；底部 = 分隔线 + 指令总数 + 「Karin 驱动 · v版本」。

### 4. 渲染胶水（新增 src/utils/render.ts）
- `createTemplateRenderer(import.meta.url, { renderer: { outputDir: path.join(karinPathHtml, dir.name) } })`（`import.meta.url` 原样传递，dev/prod 同一根解析）。
- 封装 `renderHelpImage(data)`：`renderTemplate('qbot/help', data)` → `{ success, htmlPath }` → `render.render({ file: htmlPath, selector: '#container', type: 'png', setViewport: { width: 760, deviceScaleFactor: 2 }, fullPage: false })`，返回 base64。

### 5. 命令接入（src/apps/help.ts）
- `helpGroups` 数据加 icon 字段后传入新渲染；`config().help.enable` 开关与 markdown 文本回退逻辑保持不变；仅替换图片渲染路径。

### 6. 验证
- `pnpm i && pnpm build`：确认 dist 出现 style.css + 注册表、bundle 体积合理、`node dist/index.js` 可加载。
- `pnpm template` 开发面板：切 mock 数据/深色主题，用面板截图逐屏核对视觉效果（替代浏览器目检）。
- `tsc --noEmit` + `eslint` 通过。

## 风险与对策
- **HeroUI 组件 SSR 兼容**：只选用静态原语（Chip/Card），实现时先在 ktr 开发面板截图确认再接入命令；有异常则该组件降级为 shadcn 风格自绘。
- **打包体积**：treeshake 开启 + 必要时改用 `@heroui/react` 子路径导入，构建后核对 dist 体积。
- **eslint 对 ktr/ TSX 的支持**：neostandard 若解析 jsx 报错则调整 eslint 配置（必要时忽略 ktr/，类型安全由 tsc 保证）。
